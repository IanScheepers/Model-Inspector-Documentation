# Installation

Model Inspector is a **Blender extension**, so it installs the same way as any other extension.

!!! info "Requirements"
    Blender **4.2** or newer.

## Install from a file

1. Download or build the add-on as a `.zip` archive.
2. In Blender, go to **Edit ▸ Preferences ▸ Get Extensions**.
3. Open the dropdown in the top-right corner and choose **Install from Disk…**.
4. Select the `.zip` file and confirm.
5. Model Inspector will now appear in the extensions list, enabled by default.
6. Make sure to save your preferences if auto save perferences is not enabled.

## Verify the install

Open the 3D Viewport, press ++n++ to open the sidebar, and look for a **Model Inspector** tab. If you see it then the add-on is installed correctly.
